Hollow: development kickoff

I'm starting development on HOLLOW — Path of the Sword, a 3D sword-duelling game.

By Fotoh Mbaku · 1 min read

The game

One-on-one sword duels against AI opponents. The focus is on the exchange itself: managing stamina, choosing a stance, and reading the other fighter's blade.

The plan

  • Prototype in the browser. A Three.js prototype for designing and tuning combat quickly.
  • Build the game in Godot 4. A production version for Windows, macOS and Linux that shares its combat rules with the prototype.
  • Combat first. Get one duel feeling right before adding content.
  • A toon-shaded look. Low-poly characters with ink outlines, modelled in Blender from concept sheets.

Updates

I'll post progress here as devlogs.
